# Sprint Speed & Performance Analyzer

A Python sports data analytics project for analyzing short-distance sprint performance.

## Project Objective

The project processes sprint data and calculates:

- Sprint time
- Average sprint speed
- Estimated average acceleration
- Team averages
- Athlete ranking
- Performance gap from the fastest athlete

## Dataset

The project uses a synthetic CSV dataset containing:

- Athlete
- Sprint distance
- Sprint time

## Calculations

### Sprint Speed

Speed is calculated as:

Speed = Distance / Time

### Average Acceleration

For this educational project, acceleration is estimated as:

Acceleration = Speed / Time
